# py-learning-log · Python 学习日志

> 从零开始，记录我的 Python 学习之路：基础语法 → 数据分析 → 机器学习 → 深度学习。

## 📁 板块目录

按学习路线把 Python 分成 21 个板块 + 笔记区 + 项目区，每个板块一个目录，方便随时回看和补充。

| 目录 | 板块 | 学习内容 |
|------|------|----------|
| `notes/` | 学习笔记 | 各板块的 Markdown 笔记 |
| `01-basics/` | 基础语法 | 变量、数据类型、运算符、输入输出 |
| `02-control-flow/` | 流程控制 | if/elif/else、for、while、break、continue |
| `03-data-structures/` | 数据结构 | 列表、元组、字典、集合 |
| `04-functions/` | 函数 | 定义、参数、返回值、lambda、递归 |
| `05-modules-packages/` | 模块与包 | import、自定义模块、`__name__` |
| `06-file-io/` | 文件操作 | 文件读写、with、os / pathlib |
| `07-exceptions/` | 异常处理 | try/except/finally、自定义异常 |
| `08-oop/` | 面向对象 | 类与对象、继承、多态、魔术方法 |
| `09-regex/` | 正则表达式 | re 模块、匹配、替换、分组 |
| `10-stdlib/` | 常用内置模块 | os、sys、datetime、json、random、math、collections |
| `11-numpy/` | NumPy 数值计算 | 数组、矩阵运算、随机数 |
| `12-pandas/` | Pandas 数据分析 | DataFrame、清洗、分组聚合、合并重塑 |
| `13-visualization/` | 数据可视化 | matplotlib、seaborn |
| `14-network/` | 网络请求 | requests、urllib |
| `15-spider/` | 爬虫 | 网页解析、数据抓取实战 |
| `16-database/` | 数据库 | sqlite3、SQL 基础 |
| `17-concurrency/` | 并发编程 | 多线程、多进程、asyncio |
| `18-testing/` | 测试 | unittest、pytest |
| `19-projects/` | 综合项目 | 完整的小项目 |
| `20-sklearn/` | 机器学习 | sklearn 分类任务、模型评估 |
| `21-torch/` | 深度学习 | PyTorch：MLP → CNN → CIFAR-10 → VAE |

## ✍️ 使用约定

- 每个板块一个目录，练习代码放在对应目录里
- 学习笔记统一放 `notes/`，命名格式：`序号-主题.md`
- 综合项目放 `19-projects/`，一个项目一个子目录
- 深度学习部分按 `21-torch/Torch-learning-log/` 的 Torch-N 序号顺序学习
